Understanding parallelogram properties

In a parallelogram, opposite angles are equal, and consecutive angles are supplementary (they add up to 180°). We can use these properties to set up equations for the variables t and r. From the diagram, we have:

  • m∠L = (4r)°
  • m∠M = (3t − 15)°
  • m∠O = (2t + 10)°
2

Solving for the variable t

Since ∠O and ∠M are opposite angles, they must be equal. We set their expressions equal to each other to solve for t:

2t + 10 = 3t − 1510 + 15 = 3t − 2t25 = t

Calculating the measure of angle O

Now that we know t = 25, we can substitute this value back into the expression for m∠O to find its numerical measure:

m∠O = 2(25) + 10= 50 + 10= 60°
4

Solving for r

Angles L and O are consecutive angles, meaning they are supplementary. We set their sum to 180° and solve for r:

4r + 60 = 1804r = 180 − 604r = 120r = 120 / 4r = 30
